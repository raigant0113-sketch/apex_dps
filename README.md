
# Apex Legends 武器 DPS・TTK 表（シーズン30）

非公式のファンメイドツールです。  
胴体ダメージ基準の理論値（全弾命中想定）で DPS と TTK を比較できます。

## 使い方
このリポジトリの GitHub Pages を開くか、`Apex_S30_DPS_TTK.html` をブラウザで開いてください。

## 主な機能
- ディレイ込み表示のオン/オフ
- ラピッドスナイパーストックのオン/オフ
- ショットガンボルト（無し〜紫）の切り替え
- 武器種 / 弾薬での色分け
- RPM ⇔ RPS 表示切り替え
- 各列ソート
